# Math Problem Sheet Generator

Vanilla JavaScript math worksheet generator.

## Features

- Addition, subtraction, multiplication, division, square roots, algebra, word problems
- Grade levels 1–9+
- Configurable number of problems (10–100)
- Optional work boxes
- Interactive solving with grading
- Print-optimized layout
- Answer key generation
- Shareable links (compressed base64 in query string)

## Usage

Open `index.html` in a browser, or visit the GitHub Pages site.

## Files

- `index.html` — main page
- `styles.css` — styles (including print)
- `script.js` — generation, grading, and sharing logic
